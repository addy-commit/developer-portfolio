## Run Locally

Clone the repository:

```bash
git clone https://github.com/addy-commit/developer-portfolio.git
```

Navigate into the project:

```bash
cd developer-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
